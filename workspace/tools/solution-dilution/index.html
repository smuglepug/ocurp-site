Notes

C1·V1 = C2·V2 holds only when the units match on both sides. This page converts everything to mol/L first, which needs a molecular weight for the mass-based units and a density for v/v. A v/v figure without a density is a volume ratio, not a concentration, and is only equivalent to mol/L if the density is exactly 1 g/mL. For % w/v, 1% is 1 g per 100 mL, i.e. 10 g/L. A serial ladder compounds the same factor every step and never dilutes to zero.
