Sort by Column

data — CLIENT-SIDE

Sort a CSV, TSV or pipe-delimited table by any column, auto-detecting whether that column holds numbers, dates or text. TYPE DETECTIONNUMERIC / DATE / TEXTCSV OUTCLIENT-SIDE

Auto-detect reads the column: a value that parses as a finite number is numeric, one that parses as a real date is a date, otherwise it stays text. Text sorts by locale-independent lowercase comparison, not ASCII order.
