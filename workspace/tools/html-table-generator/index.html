HTML Table Generator

Build a styled HTML table from a pasted grid, with a Markdown export and a scope option.

Paste CSV, TSV or pipe-separated data and get an escaped HTML table with a header row, plus the same grid as Markdown. CSV / TSV / PIPEHTML + MARKDOWNESCAPEDCLIENT-SIDE

How it works: the first row is treated as a header when First row is a header is on. Every cell is HTML-escaped, so <script> in your data comes out as text, never as markup.
