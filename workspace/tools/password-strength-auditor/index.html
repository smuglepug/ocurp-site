Password Strength Auditor

Audit a password's entropy, character-class spread and crack time, with the input hidden by default.

SecurityPasswordStrengthSecurity
Open now All tools

Estimates entropy from the character classes a password actually uses, then subtracts penalties for repeats, runs and known words.

Breakdown
Character classes found

How it works: the pool is the sum of the character classes actually present, so raw entropy is length x log2(pool); repeats and ascending or descending runs subtract a fixed penalty, and a hit on the embedded common-password list caps the result.
