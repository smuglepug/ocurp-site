CSV Column Slicer

Pull one column out of a CSV with a real RFC 4180 parser: quoted delimiters, embedded newlines and ragged rows handled and counted, not split on commas.

Pull one column out of a CSV. The parser is written to RFC 4180, so a quoted field containing the delimiter or a line break comes through intact, and rows that do not match the header width are counted and reported instead of being quietly padded. Give it a column number or the header name, copy the result, and check the value frequency while you are there.

Extracted
Values

A real CSV parser, not a split on commas: quoted fields containing the delimiter or a newline are handled, and rows of unequal width are reported rather than padded into shape. Auto-detect reads the header line only, which is why a file whose first row happens to contain an unbalanced quote falls back to a comma instead of shredding the whole file.
