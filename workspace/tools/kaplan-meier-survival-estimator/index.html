Kaplan-Meier Estimator

Survival from a table of event and censor times: the risk set at every step, the curve as exact fractions, Greenwood standard errors, confidence bounds and median survival.

ScienceSurvivalKaplan-MeierStatisticsClinical
Open now All tools

The estimator that made survival analysis ordinary. At each event time the survival probability is multiplied by the fraction of the risk set that survives, and censored subjects leave the risk set without counting as deaths. Every probability here is carried as an exact fraction, so the survival function is never rounded on its way to a chart. It also reports the Greenwood standard error and the median survival time.

EXACT FRACTIONS GREENWOOD SE NUMBER AT RISK

One subject per line, time event where event is 1 for a death and 0 for a censoring. Several subjects can share a time; they are grouped into one risk-set step.
