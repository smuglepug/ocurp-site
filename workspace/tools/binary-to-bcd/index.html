Binary to BCD Encoder

MATH — CLIENT-SIDE

Encode decimal digits as packed BCD, and as 5421, 2421, Excess-3 or Gray. Each digit becomes exactly one nibble, the table shows the bit pattern per digit, and the page decodes its own output back to confirm the round trip — the difference between a table that encodes and an answer you can trust.

Result
Digit by digit

Every digit becomes exactly one nibble, so a three-digit number is twelve bits regardless of which code you pick — that is what makes packed BCD a decimal encoding rather than a binary one. The page decodes what it encodes and shows the round trip, because a table that only encodes is half of an answer: 8421 cannot represent 10–15 at all, and the page refuses those digits in the 2421 and 5421 codes rather than emitting a nibble that decodes to something else.
