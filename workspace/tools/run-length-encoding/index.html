Run-Length Encoding

data — CLIENT-SIDE

The oldest compression there is, done honestly in both directions. Runs are counted in literal characters or in raw UTF-8 bytes, the encoded stream decodes back through the same function the encoder used, and the page reports whether the round trip is exact. You also get the ratio that actually matters — encoded units over input units — and a histogram of run lengths, which is why RLE wins on a table of zeroes and loses badly on prose.
