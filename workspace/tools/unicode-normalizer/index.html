Applies NFC, NFD, NFKC or NFKD, and audits the text's code points: combining marks, format characters, fullwidth forms and RTL script.

Result
Code point audit
Non-ASCII code points

How it works: the four normalisation forms come from the browser's own Unicode database; the audit counts code points, not UTF-16 units, so an astral character counts once and each combining mark is listed separately.
