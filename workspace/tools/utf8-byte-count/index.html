How many bytes a piece of text really costs. Code points, UTF-16 units and grapheme clusters are three different numbers and the page reports all three, because a character limit written by a human, enforced by JavaScript and paid for in bytes are three different budgets — and an emoji assembled from ZWJ sequences counts as one thing to the eye and several to the counter.

Counts
Where the bytes go

The gap between characters and bytes is where a 140-character SMS becomes a 420-character one. A character here means a Unicode code point, so 🎮 counts once even though your editor's caret moves four bytes over it, and an emoji built from ZWJ sequences counts as several code points while looking like one glyph — the page counts grapheme clusters too, because that is the number a human actually sees.
