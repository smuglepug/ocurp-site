Text Watermark

IMAGES — CLIENT-SIDE

Tiles rotated text across an image or a blank canvas, computes the stamp grid, and exports a PNG without the file leaving the tab.

The file is read with FileReader into a canvas in this tab. Nothing is uploaded.

Preview

How it works: the stamp footprint is size x 0.6 per character wide by size x 1.2 tall, rotated for its bounding box, then the canvas is filled with as many whole stamps as fit; the image, if any, is drawn underneath.
