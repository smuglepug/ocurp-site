CSV to SQL

Turn CSV into a CREATE TABLE statement and INSERT rows, choosing the column types for you.

Data & codeCsvSqlDatabase
Open now All tools

Turn a CSV into a CREATE TABLE plus batched INSERTs, inferring INTEGER, NUMERIC, DATE, TIMESTAMP or TEXT per column and escaping quotes as it goes. 3 DIALECTSTYPE INFERENCEBATCHEDCLIENT-SIDE

How it works: the header row becomes the column list. Every value is inspected — all-integer becomes INTEGER, a clean decimal becomes NUMERIC, an ISO date becomes DATE, an ISO timestamp becomes TIMESTAMP, and anything else becomes TEXT. Single quotes are doubled so the SQL runs as-is.
