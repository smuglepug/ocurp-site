A real entropy estimate in bits from character-class pools with a repetition penalty, an estimated crack time at 1e10 guesses per second, a common-password list check, a keyboard-walk check and a live verdict.

Password

Analysis

Entropy is a character-class pool size combined with a repetition penalty, not the length times a flat alphabet. A run of identical characters contributes far less than the same length with real variety, which is why aaaaaaaa scores so low.
