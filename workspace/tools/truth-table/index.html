Truth Table Builder

MATH — CLIENT-SIDE

A truth table for up to six variables, in the order digital logic actually uses: binary counting with the first variable as the most significant bit, plus the minterm index Σm and maxterm index ΠM so a table drops straight into Karnaugh work or a sum-of-products derivation. Copy it out as tab-separated text for a spreadsheet or a text editor.

Shape
Table

Rows run in binary counting order with the first variable as the most significant bit, so row m of the minterm index is exactly the assignment whose bits read as m in binary. Six variables give 64 rows; a seventh is refused rather than silently truncated, because a truncated table would be a wrong table.
