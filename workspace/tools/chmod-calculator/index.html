Turn an octal file mode into the symbolic form, the decimal value and a plain reading of who can read, write or execute. OCTALSETUID / SETGIDSYMBOLICCLIENT-SIDE

Each digit is one group: owner, group, other. 4 = read, 2 = write, 1 = execute. A leading 4th digit is the setuid/setgid/sticky bit.
