JSON Pointer Resolver

Resolve an RFC 6901 JSON Pointer against a document, with array-index and URI-fragment encoding.

Resolve an RFC 6901 pointer against a JSON document, with correct ~1/~0 unescaping and readable errors for bad indices and missing keys. RFC 6901~0 / ~1 ESCAPINGCLIENT-SIDE

How it works: the pointer is split on /, unescaped with ~1 → / and ~0 → ~ — in that order, since the other way round corrupts the key a~1b. Each token is then used as an object key or an array index. An empty pointer returns the whole document.
