JWT Token Inspector

Security — CLIENT-SIDE

Decode a JWT's header and payload without verifying the signature, with base64url handled correctly, the algorithm flagged as claimed-only, and an expiry check. This is a debugger, not an authorisation check.

Token

Decoded

This does not verify anything. The header and payload are only base64url-decoded - their contents are attacker-controlled. Trust nothing here until a server has checked the signature with a key it holds. Use it for debugging, never for authorisation.
