What this is

Base58 is Bitcoin's alphabet: it drops 0, O, I and l so a mistyped address is obvious. Unlike Base64 it has no padding, and the leading 1 in a Bitcoin address encodes leading zero bytes.

Unicode input is encoded as UTF-8 first, so emoji and accents round-trip correctly.
