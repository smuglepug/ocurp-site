Notes

A z-score is how many standard deviations a value sits from the mean. |z| < 2 is roughly 95% of a normal distribution, |z| > 3 is outside what 3σ of 99.7% allows. It is meaningful only against the same population you computed the mean and SD from — a z-score from an all-time-best benchmark is not the same statistic as one from this season. With SD = 0 every value equals the mean and z is undefined, so this page reports an error instead of a number.
