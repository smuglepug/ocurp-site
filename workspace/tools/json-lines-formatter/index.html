JSON Lines Formatter

Data — CLIENT-SIDE

Parses one JSON value per line and re-serialises it, pretty, compact, or wrapped in an array, with sorting, duplicate removal and a byte count. A malformed line is reported by line number while every other line still formats.

Each line is parsed and re-serialised independently, so a bad line is reported with its line number while the rest still format. Key order is preserved, not alphabetised.
