Hamming Distance

DATA — CLIENT-SIDE

The number of positions in which two sequences differ, for text, binary words or DNA. Select the alphabet and the page validates the input before counting, so a stray G in a DNA sequence is a clear error rather than a distance of quietly wrong magnitude. Length differences count, positions are listed one by one, and the normalised distance lets you compare sequences of different sizes.

Result
Position by position

Unequal lengths are not padded silently: the length difference is added to the mismatch count, which is what makes this the same number as Levenshtein distance with unit substitution and insertion costs. So abc against abcd is 1, not 0 — a comparison that reported 0 there would be wrong about how far apart two sequences are.
