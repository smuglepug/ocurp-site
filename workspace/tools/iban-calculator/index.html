Checks an IBAN against the country's registered length and the mod-97 remainder, then shows the check digits the format actually demands.

Type any of the ~80 registered formats; length and mod-97 are both checked.

Result

How it works: each country code carries a fixed total length, and the check digits are 98 minus the remainder of the IBAN rotated left by four, taken mod 97.
