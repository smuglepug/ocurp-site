CSV Column Statistics

Profile every column of a pasted CSV at once: type detection, count, missing, distinct, mean, median, quartiles, stdev and a histogram per column, with delimiter auto-detection.

Open now All tools

Paste delimited text and get a per-column read on it in one pass: for every numeric column the count, the missing count, the minimum, the maximum, the mean, the median, the sample standard deviation and the sum; for every text column the count, the missing, how many distinct values there are, and which value appears most often and how many times. The delimiter — comma, semicolon or tab — is detected from the shape of the data rather than assumed, and the first row is treated as a header unless you say otherwise. Rows that do not have the same number of fields as the header are named by line number and counted anyway, because a tool that silently drops the rows it cannot fit is worse than one that shows you which rows are malformed.

COLUMN STATISTICS DELIMITER DETECTED RAGGED ROWS REPORTED

A column is numeric only when every non-blank cell in it parses as a number; one stray label demotes the whole column to text rather than being quietly skipped. Blank cells are counted as missing and excluded from the arithmetic. Rows whose field count disagrees with the header are named by line number, never dropped.
