Hungarian Assignment Solver

mathematics — CLIENT-SIDE

Give it a square cost matrix and it returns the cheapest one-to-one matching: one worker per job, nobody used twice. The search is the Hungarian algorithm in O(n cubed), and because an algorithm being clever is no evidence it is right, every matrix of eight or fewer gets its answer re-derived by enumerating all n! permutations and comparing. Matrices with ties get their tie count reported too.

KUHN-MUNKRES BRUTE-FORCE CHECK TIE DETECTION

Rows separated by spaces, columns by commas or spaces: 4 1 3 / 2 0 5 / 3 2 2. Row i column j is the cost of putting i on j. All costs may be negative.
