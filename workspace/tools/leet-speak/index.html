Writing & textLeetTextConvert

Convert text at four intensities from a handful of obvious lookalikes to a full letter swap, counting every substitution and listing the rules fired. 4 INTENSITIESRULE LEDGERCLIENT-SIDE

How it works: level 1 replaces letters that have an obvious lookalike (E→3, I→1, O→0, S→5, T→7). Higher levels add the weaker pairs (Z→2, G→9, B→8) and start swapping letters that only rhyme. Substitution is deterministic per character, so the same text always gives the same output.
