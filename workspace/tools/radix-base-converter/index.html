Radix Base Converter

Convert between any bases from 2 to 36 in both directions with negatives and fractional digits kept exact, plus a live table of the same value in all 35 bases.

Math & convertBaseRadixHexBinary
Open now All tools

Convert between any two bases from 2 to 36 in both directions, keeping negatives and fractional digits exact rather than rounded away. A live table shows the same value written in all 35 bases at once, so a hex digest and its binary form can be read side by side.

Input

Fractional digits are converted by repeated multiplication by the source base, so 0.1 in base 10 is 0.333333 in base 3 rather than a rounded lie. A leading minus sign is always accepted. The table below is generated from the same value, one row per base.
