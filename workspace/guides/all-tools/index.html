What this is

These are utility pages that do one job each, and they are all built the same way: the work happens in your browser, in JavaScript, on the machine you are reading this on. When you drop a PDF, a photo or a folder of images into one of these tools, the file is read by the browser itself and processed locally. It is never posted to a server, because there is no server to post it to.

That is the whole point, and it is not a marketing line. Online converters ask you to upload a document full of personal information because their business model needs your file to exist on a disk you do not control. These tools skip that step: a colour converter needs no file at all, a PDF splitter reads the bytes you selected, and the result is handed straight back to you as a download. Close the tab and nothing is left behind.

There is no account, no email address and no trial. Open a page, use it, close it. If you later want to keep projects or starred tools across devices there is an optional sign-in for that, but nothing on this page requires it, and no tool is gated behind it.

Questions people actually ask

Are these tools really free?
Yes. Every one of the 170 is free to use with no trial, no tier and no watermark. There is nothing to pay for and nothing to cancel. The pages are static HTML, so there is no account system to bill against either - the site does not need one to serve you a tool.
Do my files get uploaded anywhere?
No. Your files are read with the browser's own File and Blob APIs and processed in JavaScript on your device. There is no upload endpoint that receives them, so a document, photo or recording you drop into a tool does not travel to a server. Two tools make a deliberate outbound request and are the honest exceptions: IP & UA Inspector asks ipify for your public IP address, and UTM Builder's short-link button calls a public URL shortener when you press it. Neither ever sends your files.
Is there a limit on how much I can convert?
There is no account and no quota, because there is no server to impose one. The only real limit is your device: how much memory the tab can hold while working on a file. Very large PDFs and long videos are better handled a chunk at a time - Batch Image Compressor will take a whole folder and return one ZIP.
Does it work offline?
Mostly, and it is worth being precise about why. The styling and a handful of PDF, OCR and archive libraries are fetched from public CDNs the first time a page loads, so the very first visit needs a connection. After that the page is cached and the actual work happens locally, so the converters, generators, editors and games keep working with no network at all.
Do I need an account?
No, not to use anything. Sign-in exists for saving things between devices - saved projects, starred tools - and it is entirely optional. Everything on this page works signed out, and the things that save locally, like the Kanban board and your flashcard decks, stay in this browser's storage without any account.
Can I use them on a phone?
Yes. The pages are responsive down to a 390px screen, which is two columns of tools and a stacked layout. Touch-friendly tools like the Signature Generator, Stopwatch and drawing pad take pointer input directly, and the audio recorders use the phone's microphone.
