Lantern Path

Puzzle — Client-side

CLICK A TILE TO TURN IT 5 BOARDS × 4 LAYOUTS PROVED SOLVABLE

The lantern sits in the top-left tile, the door in the bottom-right. Clicking a tile turns it a quarter turn clockwise; every tile the lantern has reached lights up so you can see how far the light has travelled. Light reaches the door when every edge along some route points the right way. Each layout was cut from a spanning tree, so aligning all the tiles always opens a way through — the puzzle is finding it, never whether one exists.
