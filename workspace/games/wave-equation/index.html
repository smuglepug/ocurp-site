The probe trace under the string is the displacement at mid-span. Count the crests to measure the period yourself and compare it with fₙ = nc/2L.

Explicit leapfrog scheme, u⁶⁶ = c²u⁹⁹, run at 0.4×the CFL limit so it stays stable at any speed. The substep count shown is the stability cost.
