Towers

Place one tower per row and column so no two can see each other.

Puzzle
Play now All games
3 MISTAKES AND YOU LOSE

Each number says how many towers you can see along that line, counting from the edge. A taller tower hides every tower behind it, so two towers in the same row or column must never see each other. Every row and every column holds exactly one tower.

Click a cell to place a tower, click it again to lift it.
