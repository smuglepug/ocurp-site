THE EXACT RULES
Targets n=1..30 shrink from 64 px to 26 px and are placed 70–(120+210·(n-1)/29) px from your last click, so the indexing difficulty ID = log2(D/W + 1) rises smoothly. The per-target budget is max(850, 1.6 · (110 + 190 · ID)) ms, which is 1.6× the Shannon-form predicted movement time at every single level, so a normal player always has 60% headroom. FAIL = the budget runs out on any target. WIN = all 30 targets clicked in time. Best ID is kept in localStorage.
